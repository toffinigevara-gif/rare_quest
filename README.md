# RARE QUEST — стартовый сайт и схема backend

В проекте есть тёмный русскоязычный сайт-прототип и демо-панель управления квестами. В `supabase/schema.sql` добавлена стартовая схема базы данных и политики доступа для Supabase.

## Запустить прототип
Откройте `index.html` в браузере. Добавление/удаление квестов в демо-панели хранится только в localStorage текущего браузера.

## Опубликовать сайт на Vercel
1. Создайте аккаунт на https://vercel.com/ и войдите.
2. Создайте репозиторий на https://github.com/ и загрузите в него содержимое папки `rare-quest-starter`.
3. В Vercel выберите **Add New → Project**, импортируйте репозиторий и нажмите **Deploy**. Для текущего статического прототипа выберите preset `Other`; build command и output directory оставьте пустыми.

## Подключить Supabase (следующий этап)
1. Создайте проект на https://supabase.com/.
2. Откройте **SQL Editor**, вставьте содержимое `supabase/schema.sql` и выполните.
3. Зарегистрируйте обеих владелиц через Supabase Auth.
4. В SQL Editor назначьте роль `owner` двум аккаунтам по их UUID (UUID можно взять в Authentication → Users):

```sql
update public.profiles
set role = 'owner'
where id in ('UUID_ПЕРВОЙ_ВЛАДЕЛИЦЫ', 'UUID_ВТОРОЙ_ВЛАДЕЛИЦЫ');
```

5. Включите Realtime для таблицы `public.messages` в настройках Database → Publications.
6. Создайте Storage buckets для обложек и медиа, задайте отдельные политики доступа.
7. Подключите Supabase Auth/Database/Realtime к интерфейсу сайта. Не помещайте `service_role` key в браузер и не открывайте админские права всем зарегистрированным пользователям.

## Что уже есть и чего пока нет
- Есть: главная, каталог из семи стартовых историй, Telegram-ссылка, адаптивная вёрстка, локальная демо-панель.
- Заготовлено: схема таблиц пользователей, квестов, персонажей, сессий, сообщений, избранного и отзывов; базовые RLS-политики.
- Ещё не реализовано: подключение реальной авторизации к интерфейсу, полноценная совместная админка, живой чат, назначения ведущих из UI, загрузка медиа, уведомления и личный кабинет. Поэтому пока не собирайте реальные пользовательские данные и не объявляйте демо-панель защищённой админкой.

## Контент
В каталоге стоят семь названий из исходного сайта. Перед публичным запуском проверьте описания, обложки, возрастные отметки и доступность каждого сценария. Фотографии владелиц нужно добавить отдельными исходными файлами в проект.
